# Jogo do número secreto

Jogo simples no navegador: o computador sorteia um número de 1 a 10 e você tenta adivinhar. A cada chute, o jogo diz se o número secreto é maior ou menor e, quando você acerta, mostra em quantas tentativas.

**Jogar online:** https://wpbispo.github.io/jogo_do_numero_secreto/

Exercício do curso de lógica de programação com JavaScript da Alura (2025).

## O que pratiquei

- **HTML e CSS:** estrutura da página, campo de número e botões.
- **JavaScript:** variáveis, funções, `if/else`, operador ternário e template strings.
- **DOM:** `document.querySelector` para ler o chute e trocar os textos da tela.
- **Listas:** o número sorteado não se repete até todos os números saírem (`includes` e `push`).
- **Recursão:** a função de sorteio chama a si mesma quando o número já foi usado.
- **Biblioteca externa:** [ResponsiveVoice](https://responsivevoice.org/) para o jogo ler os textos em voz alta.

## Como rodar

Baixe os arquivos e abra o `index.html` no navegador.
